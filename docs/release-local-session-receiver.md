Prepared on 11 October 2026. Coordinated local checks and ordered build/source receipt are complete. Native source-only save evidence follows separately. ## Change and isolation

The loopback HTTP receiver wraps the unchanged fixed standard-input Session runtime. That child retains the existing POSIX writer lock, complete recovery reconstruction, atomic file/parent-directory persistence and original event receipt semantics. The receiver verifies the matching retained journal before acknowledging work and exposes only confirmed state.

Separate generated local tokens authenticate producer input and owner monitoring/control. Only digests are persisted in a strict local file. Browser credential entry is memory-only. Exact Host, Origin and security-header checks, bounded requests/queues/connections and failure isolation constrain this local connection.

The local monitor uses fixed self-hosted HTML, JavaScript and CSS, renders supplied text safely and shows real strategy/position/risk/mark timestamps. Public `/session` explains the sponsor-local path; it does not bridge a hosted browser to localhost or acquire credentials.

The Session engine/model/journal and their pins, existing runtime, evaluators, dependencies, migrations, publication models/stores/HTTP routes, public grants and private application remain unchanged. No exchange adapter, new expense, paid inference, live execution, automatic publication, remote bind or production configuration is introduced.
