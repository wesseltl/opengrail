# Research and venture agent assistance review

The source increment connects a human evidence request, an external agent’s exact research proposal and a deliberately edited human fork. It serves general research and structured venture diligence through the existing publication and assistance lifecycles. Agents can challenge a claim and answer UNKNOWN; a response does not qualify evidence, recommend an investment or acquire execution authority.

The version-two assistance contract adds an explicit domain, one to five bounded objectives, source/content references and one source-linked answer per objective. V1 strategy serialization, default feeds, policy, fixed role and existing quotas remain unchanged. No new database migration, dependency or runtime configuration is introduced. Public V2 interpretation still requires maintainer rollout approval.

The separate `/assistance/research` workspace exposes full proposals, source references, conflicting answers and edits before explicit human publication through the existing research writer. Exact identity, digest, source lifecycle and current human account checks protect pending operations. Uncertain responses retain the original request identity and bytes for reconciliation. The machine guide contains synthetic examples and never invokes a model, writes a publication or accesses private account data.

The home page now identifies the source as public and places secondary workspaces in a native expandable menu. The exact frozen test/build results are recorded in [the validation receipt](../validation/research-agent-assistance-20261011.json). Separate local rendered QA is reported with its explicit scope; source, local checks and hosted acceptance remain separate.

Full goal gaps remain: actual useful outside contributors and retention, independently qualified evaluation with authentic data/custody, programmable strategy isolation, reputation grounded in accepted evidence, hosted onboarding/CI and an approved rollout. This increment does not close those gaps. Live orders, investments, transfers and paid inference remain disabled.

Rollback is a reviewed return to the prior source and saved version, subject to maintainer rollout approval. No production state has been migrated or deployed by this increment. The repository’s software license and contribution terms remain undecided.
