# Carry an exact strategy into Demo or Sessions

The strategy hub's **Try Demo** and **Open Session** links carry the selected immutable strategy ID and digest. They open the existing replay or incremental Session page; they do not start computation, create a journal or confirm data rights.

The receiving page requests that exact public definition, including versions outside the first catalog page. A later revision is not a substitute. Malformed or incomplete references, duplicate/unknown query fields, hidden content, wrong metadata and a mismatched canonical digest fail closed. An ordinary empty query still opens the catalog and its separate synthetic example.

## Local replay

1. Choose **Try Demo** on the desired visible strategy version.
2. Review its rules, risk and chosen fee/slippage assumptions. Import permitted replay input or explicitly generate the labeled synthetic example.
3. Confirm rights and run the existing bounded local replay. Export the exact input if registering an experiment before computation.

The page checks current public content before and after replay and before exporting dependent material. Known source suppression clears held inputs and result bodies while safe attempt identities and adverse/interrupted dispositions remain. A transient server failure withholds fresh work or export; it is not evidence that the source was withdrawn. Existing exports cannot be recalled.

## Prepare a sponsor-local receiver

1. Choose **Open Session** for the exact strategy.
2. Before starting a browser journal, choose the system receipt clock, review virtual capital and enter the supplied source label and data permission note.
3. Confirm input rights and explicitly export the local receiver setup. The export contains a strict Session configuration with `SYSTEM_RECEIPT`, `PUBLIC_STRATEGY`, `USER_SUPPLIED` provenance and the exact reviewed strategy. Its rule, risk and cost fields are preserved; Live and orders stay disabled.
4. Save that file in the ignored `work/local-session/` directory or outside the checkout. Use it as the configuration input to the existing [local receiver](local-session-receiver.md). The receiver still requires Node.js and Linux/Python/POSIX locking; it is not installed or launched by the website.

An unchanged prepared setup keeps its session ID on repeat exports. Changing the strategy or setup clears the prepared file identity and resets rights confirmation. Exporting a configuration creates no journal, start time, event, price, position, credential, deposit or server-side session. An existing browser journal is a different retained history: use its checkpoint export and recovery workflow instead of restarting its exposure from a fresh configuration.

The browser freshly checks the public source before and after preparing a configuration and checks the captured form/lifecycle again before download. Source suppression, navigation, signout or unmount prevents late downloads from restoring cleared content. Temporary unavailability blocks confirmation without pretending a source is hidden.

## Exact data and authority boundaries

The query accepts only `strategy=<lowercase UUID>&digest=<lowercase SHA-256>` within its 512-byte limit. Links are fixed relative paths. The page fetches only the existing same-origin public detail route; it never follows a contributor URL or sends a caller-selected command.

Source labels and data-rights notes are declarations. A valid public record hash is content consistency, not data authenticity, correct strategy execution or independence. All results remain author reported, untested or unqualified under the existing methods. No untouched holdout, connected Altfins/TradingView/exchange feed, unattended operation or profitability is implied.

Never put producer, owner or public agent tokens into a URL, source label, data note or configuration. The website neither accepts nor creates local process credentials. Create them explicitly on your machine using the receiver's existing credential command, and keep raw tokens outside logs and Git.

This handoff adds no grant, public webhook, network-to-loopback bridge, private account connection, production policy, paid inference or new expense. Public deployment and real-browser/hosted acceptance remain separate gates. See [task 010](tasks/010-exact-strategy-handoff.md).
