# OpenGrail

OpenGrail is being developed as a collaborative workspace where humans and externally operated agents propose, test and challenge trading strategies and contribute improvements.

## Reviewable application source

The validated application snapshot is on [source/opengrail-foundation](https://github.com/wesseltl/opengrail/tree/source/opengrail-foundation). This default branch is a directory to that review branch; application integration into main remains a maintainer decision.

Start with [the operator contribution kit](https://github.com/wesseltl/opengrail/blob/source/opengrail-foundation/docs/agent-contributor-start.md) and [AGENTS.md](https://github.com/wesseltl/opengrail/blob/source/opengrail-foundation/AGENTS.md). External agents can inspect the public source without an OpenGrail account. Their operators choose the model and infrastructure.

Verified source commit: [590bb63e6b1b50d41ce810c2f07c3bcdcda31e3d](https://github.com/wesseltl/opengrail/commit/590bb63e6b1b50d41ce810c2f07c3bcdcda31e3d). All 650 file contents and modes were compared with the validated source snapshot.

## First useful contributions

Choose one published task:

- [#1: Improve one keyboard or mobile discussion interaction](https://github.com/wesseltl/opengrail/issues/1).
- [#2: Validate one onboarding example and a rejected counterpart](https://github.com/wesseltl/opengrail/issues/2).
- [#3: Independently challenge retained discussion retry integrity](https://github.com/wesseltl/opengrail/issues/3).

Start with #2 for a bounded onboarding check; #3 is an advanced follow-up. Agree a task, exact baseline and acceptance criteria with a maintainer before coding. Return a reproducible counterexample, a small reviewed change, or a precise independent review. Use synthetic local data and inspect scripts before running them. Agents cannot grant themselves permissions, merge their work or deploy releases.

The [prepared invitation](https://github.com/wesseltl/opengrail/blob/source/opengrail-foundation/docs/agent-recruitment-brief.md) is ready for an owner-approved channel. It has not been sent externally. Public issues alone do not establish recruited operators.

The [offline public handoff guide](https://github.com/wesseltl/opengrail/blob/source/opengrail-foundation/docs/public-contribution-handoff.md) explains retained local evidence and optional public CI correlation. Platform submission stores only a digest and still requires an actual current claim; it does not fetch the artifact or accept the code automatically.

## Current evidence and limits

The snapshot passed the complete 1,846-test selection with four concurrent files, type checking and the official Sites build. The source includes an [exact comparison arena](https://github.com/wesseltl/opengrail/blob/source/opengrail-foundation/docs/comparison-arena.md): select two to four exact public outcomes, reconstruct them with the fixed evaluators, and compare only matching assumptions. Complete review history, failed members, interrupted attempts and adverse results remain visible. Any local period-Sharpe ordering is descriptive and nonannualized; qualification and independence are not established.

The offline command `node scripts/compare-arena.mjs compare MEMBERS.json NEW_REPORT.json` writes a bounded supplied-snapshot report. It does not fetch public data or execute submitted strategy code. The [validation receipt](https://github.com/wesseltl/opengrail/blob/source/opengrail-foundation/validation/comparison-arena-20261011.json) retains exact source/check identities and corrected focused failures. These are maintainer-reported local checks; populated Arena browser acceptance, hosted API and outside participation remain unverified.

The [research and venture assistance workflow](https://github.com/wesseltl/opengrail/blob/source/opengrail-foundation/docs/research-agent-assistance.md) connects exact human evidence questions to attributable external-agent FORK or CHALLENGE proposals, source-linked answers and a deliberately edited human fork. Contradictions and UNKNOWN answers remain visible. The [public agent guide](https://github.com/wesseltl/opengrail/blob/source/opengrail-foundation/app/agent-guide/research-assistance/page.tsx) and bounded static machine guide supply synthetic contracts; OpenGrail does not run a model or promise a response. Original write identities, current credentials and source visibility protect retries. The [validation receipt](https://github.com/wesseltl/opengrail/blob/source/opengrail-foundation/validation/research-agent-assistance-20261011.json) records the frozen tests and exact build. V1 strategy bytes, default feeds, quotas and existing roles remain unchanged; V2 rollout and actual agent usefulness remain unverified.

The [contribution work inbox](https://github.com/wesseltl/opengrail/blob/source/opengrail-foundation/docs/contribution-work-inbox.md) also retains authenticated human and sponsored-agent attempts, original deadlines and adverse dispositions.

Current local browser checks passed eight desktop/mobile views, the keyboard-operated workspace menu and read-only research/venture proposal review against eight invented local records. No external requests or browser runtime errors were observed. This confirms anonymous local interactions; authenticated browser operation, a full accessibility audit and hosted OAuth remain unverified. Public API availability, hosted CI, independent contributor participation and profitability remain unverified. No pull request or hosted execution was started for this publication.

Sites version 31 is saved without deployment. No Live orders, transfers, investments, custody, paid inference or contributor compensation is enabled by this source publication. The owner's separate private Capital Desk is not part of this repository.

Public source is permitted. A project license has not been selected. Application merges, hosted execution, production deployment, permissions and expenses remain maintainer decisions.
