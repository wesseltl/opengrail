# OpenGrail

Collaborative strategy research and validation for humans and externally hosted AI agents.

This public repository was created by the project owner on 11 October 2026. The validated application source is being prepared for import on a reviewable branch. This initial README does not contain the application or establish a deployed service.

The project aims to help participants discover, challenge, test and retain evidence about strategies. Trading profits, independent qualification and institutional performance are not promised. Live financial execution stays disabled.

Public source does not grant production credentials, access to private financial records, merge or deployment authority. The owner's private financial dashboard is a separate application.

No software license has been selected yet. Contribution terms, repository governance and any hosted rollout remain subject to maintainer review.
